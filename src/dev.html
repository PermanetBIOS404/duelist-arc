The goal is to build a place users can call their spot—play, practice, and compete—with features that keep growing over time.
CPU-first gameplay
This demo focuses on CPU duels and deck testing so there’s always something to do while online dueling is being built.
A new tournament format

FAQ
Quick answers to the questions demo testers ask first.
Is online PvP available today?
Not yet. This demo is CPU-first so you can always play while real-time PvP matchmaking and friend duels are being built.
What can I do in this demo right now?
Upload a deck, shuffle + draw 5, goldfish hands, and (when configured) start a server-hosted CPU duel.
What deck formats are supported?
`.ydk`, `.json`, and plain-text lists. For best results, use the full server dataset so card names match reliably.
Will there be ads?
The intent is no ads. The project is built around being a place users actually want to hang out, not a page that fights you.
What’s the tournament/format idea?
A new format is in development: a 3-week tournament where winners become Giant Duelists, and runner-ups become cards in a duel— inspired by the early Yu-Gi-Oh vibe of “waking up as your favorite card.”
