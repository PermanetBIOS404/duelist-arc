# Yu-Gi-Oh Card Viewer — Progress Log
**Date:** April 8, 2026

## Summary
Focused on turning the project into a practical “deck testing lab” for consistent goldfishing + AI coaching:
- Added a manual **Goldfish** panel (zones + actions) and an **AI summary export**.
- Upgraded deck consistency tooling with role tagging (Starter/Extender/Handtrap/Brick), bulk apply from current filters, and target-based Monte Carlo odds.

## Shipped Today
### A) Goldfish loop (manual testing)
- New **Goldfish** panel under the deck area:
  - **Opening size** selector (5/6)
  - **New hand / Mulligan / Keep / Draw 1 / Next turn / Reset**
  - Zones: Hand / Field / GY / Banish with one-click moves
- Current hand shows:
  - Role counts in-hand (S/E/H/B)
  - Whether the hand **meets the current Target**
- **Copy AI summary** copies a compact, paste-ready summary including:
  - Deck sizes + dataset label
  - Role counts (copies + unique)
  - Target constraints
  - Current goldfish zones and whether the current hand meets target

### B) Odds + targets (consistency testing)
- Role tagging now supports **Starter / Extender / Handtrap / Brick**.
- Bulk tools can apply roles based on the **current filtered card view** (only affects cards present in Main deck).
- Target builder supports presets + min/max constraints:
  - Starter ≥ N, Extender ≥ N, Handtrap ≥ N, Brick ≤ N
- Odds UI remembers Trials/Hand size and can optionally use **Target per hand** (separate targets for Hand=5 vs Hand=6).
