# Yu-Gi-Oh Card Viewer — Progress Log
**Date:** March 20, 2026

## Summary
Converted the prototype into a single runnable viewer under `src/` and added real app features: card selection/details, search + filters, favorites, shareable URLs, and a basic deck panel.

## Key Outcomes
- One working entrypoint:
  - Viewer lives at `src/index.html` (served via a local web server).
  - Root `index.html` / `card.html` redirect to `src/`.
- Viewer UX:
  - Clickable grid + right-side detail panel.
  - Search (name/effect/type/attribute) with `Esc` to clear.
  - Filters: Type, Attribute, Favorites.
  - Sorting: name, level, ATK, favorites-first.
  - Keyboard: `/` focuses search; `f` favorites a focused card.
- Persistence + sharing:
  - Favorites stored in `localStorage`.
  - Deck stored in `localStorage`.
  - URL state:
    - Selected card stored in `#card=<id>` (stable).
    - Filters stored as query params (`?q=...&type=...&attr=...&fav=...&sort=...`).
- Deck (lightweight):
  - Add/remove from detail view.
  - Deck list with +/- quantity controls.
  - Deck name.
  - Export/import via JSON (clipboard/prompt).
