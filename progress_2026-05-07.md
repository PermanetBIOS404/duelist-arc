## Static-Only Launch Pivot (Cloudflare Pages Readiness)

### Why

Cloudflare Pages static hosting does **not** run `server/` (Node/Express). Many features depend on backend routes like `/auth/*`, `/me`, `/duel/*`, `/decks`, etc.

### What was implemented

- Added a clear visitor-facing banner:
  - `src/index.html` — `#static-build-banner`
- Added backend detection and static-mode UI switching:
  - `src/js/main.js`
  - Detects backend availability via `GET /healthz` (timeout)
  - If backend is unavailable:
    - Shows the static banner
    - Hides backend-only controls (CPU duel/session/local duel/auth UI)
    - Removes the “Dataset: Server (All cards)” option
    - Skips backend bootstrapping and backend polling loops
    - Keeps static-safe CTAs working (upload/sample/draw5/tour/realms)
