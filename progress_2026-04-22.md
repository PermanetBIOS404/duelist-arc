  - local accounts (handle switcher + create)
  - season phase display (3-week tournament + 2-week intermission)
  - **Season controls** (local prototype):
    - Start new season (increments season id)
    - End tournament now (finalize qualifiers snapshot + switch to intermission)
  - local **Start match** → **Complete match** flow (ranked stub)
    - match format (TCG/OCG/GOAT)
    - deck selection for you + opponent (uses saved decks)
  - standings (top 10) computed from recorded matches
  - intermission role preview (Giant Duelists / Living Cards) uses **finalized snapshot** when available
  - **Anti-farming rules** (prototype):
    - counted matches per day cap
    - counted matches per opponent per season cap
    - matches can complete but be marked “not counted” in Recent
  - **Season stats table** (counted): points + W/L/D + counted matches per player
  - Platform state tools:
    - Export JSON
    - Import JSON
    - Reset platform-only state
    - Delete matches (pending or completed)
  - **Intermission gameplay layer (prototype)**:
    - Giant Duelists pick a deck + assign Living Cards into 8 “slots”
    - Living Cards submit limited actions (request summon/set/activate/hold)
    - Event log captures actions (last 25)
