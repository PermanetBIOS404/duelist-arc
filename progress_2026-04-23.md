## Dueling Direction (EDOPro + WindBot)

Status: wiring is in place, but a full in-browser duel field UI is not implemented yet. The “Duel” tab currently acts as a launcher / status panel.

- `server/src/routes/duel-core.js`
  - `GET /duel-core/health`
  - `POST /duel-core/smoke` (spawn CoreIntegrator, run one process tick, exit)
- `server/src/routes/cpu-duel-edopro.js`
  - `POST /cpu-duel/edopro/start` creates an EDOpro-server-ts room via its HTTP API and spawns WindBot to join.
  - `POST /cpu-duel/edopro/stop` stops the bot for that duel id.
- Docs:
  - `server/DUEL_CORE_EDOPRO.md`
  - `server/DUEL_CPU_WINDBOT.md`

Known blockers in the sandbox:
- Building `CoreIntegrator` requires `cmake` + other packages installed via `apt-get` (sudo). In this sandbox, `sudo` prompts for a password, so compilation was not completed here.
