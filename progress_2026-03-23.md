# Yu-Gi-Oh Card Viewer — Progress Log
**Date:** March 23, 2026

## Summary
Extended the prototype into a more scalable “local-first” viewer:
- Dataset loading (manifest + local JSON import)
- Deck builder upgrade (Main/Extra/Side)
- UX + performance polish (event delegation, keyboard navigation)

## Key Outcomes
### Datasets
- Added `cards/datasets.json` manifest and a dataset selector in the UI.
- Added “Load JSON” to import a local dataset file into localStorage.
- Card normalization layer:
  - Ensures `id` exists and is unique
  - Normalizes common fields (name/type/attribute/level/atk/def/effect)
  - Adds optional `image` support for grid + detail views

### Deck Builder
- Upgraded deck format to v2:
  - Sections: Main / Extra / Side
  - Backward compatible import of v1 deck JSON
- Detail pane now supports adding to specific section (+ Main / + Extra / + Side).

### UI / Quality
- Grid rendering uses event delegation (fewer listeners, faster updates).
- Keyboard navigation:
  - Arrow keys move focus in the grid
  - `Enter`/Space selects
  - `f` toggles favorite on focused card
  - `/` focuses search, `Esc` clears filters

## Files Changed / Added
- Updated:
  - `src/index.html`
  - `src/js/main.js`
  - `src/css/style.css`
- Added:
  - `src/cards/datasets.json`

## Additional Work (Later Same Day)
### Better real-world dataset compatibility
- Dataset import now supports:
  - A raw JSON array of cards (current format)
  - An object with a `data` array (YGOPRODeck-style JSON structure)
- Normalization expanded with optional fields:
  - `race`
  - `archetype`
  - Better image extraction (supports `card_images[0].image_url_small` / `image_url`)

### New filters + URL persistence fixes
- Added filters:
  - Race
  - Archetype
- Search now matches against `race` and `archetype` fields.
- Fixed query-param persistence so type/attribute filters restore correctly (values are no longer lowercased in the URL).
- Updated the sample dataset to include `race` and `archetype` so the new filters are visible immediately.

### Dataset import UX (validation panel)
- Added a **Dataset details** dropdown panel showing:
  - card count + detected import format
  - field coverage (present/total) across common fields
  - warnings for duplicates / missing key fields

### Advanced filters + deck polish
- Added numeric filters (min/max): Level, ATK, DEF (URL-persisted like the other filters).
- Deck panel now shows per-section totals (Main/Extra/Side) and basic non-blocking cap warnings.
- Added **Copy list** export (plain text) alongside JSON export.

### Deck manager + auto section add
- Added support for multiple saved decks (localStorage), with a deck selector and New/Duplicate/Delete actions.
- Added **+ Auto** in card details to add to Main vs Extra based on card type text.

### Deck list import + browsing UI upgrades
- Added **Import list** to bring in a plain-text deck list (with optional section headers).
- Added view controls: Comfortable/Compact density, thumbnail size, and a hover/focus preview toggle.

### Real-card fields + YDK + file workflows
- Normalization and details now support more real-card fields when present (e.g., `frameType`, `scale`, `linkval`, `linkmarkers`, `sets`, `banlist`).
- Added Kind filter (Monster/Spell/Trap) and upgraded type parsing for **+ Auto**.
- Added YDK import/export and file-based import/download for deck formats.

### Browsing polish (image viewer + layouts + performance)
- Added image modal viewer (thumb/detail click) with keyboard navigation and zoom.
- Added saved UI layout profiles (save/switch/delete) to quickly restore preferred browsing setups.
- Grid rendering now chunk-renders very large lists to stay responsive.

### Segment B start (advanced filtering + smart search)
- Added tag/subtype filters (monster tags + spell/trap subtypes) based on parsed `tags`.
- Added TCG/OCG/GOAT banlist filters (Forbidden/Limited/Semi) when dataset provides banlist info.
- Search now supports simple operators like `tag:link`, `kind:monster`, `atk>=2000`, plus free-text terms.
- Added quick chips for common tag/kind/banlist filters, and a Search help panel.

### Segment C start (deck workflow quality)
- Added per-deck notes and “last edited” timestamps (localStorage).
- Added a soft warning for over-3-copies (across all sections).
